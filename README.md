# Akiko的每日打卡

一款帮助建立日常习惯的 Android 每日打卡应用。你可以为每个习惯设置每日打卡次数和提醒时间，在提醒到达时通过通知、铃声和震动获得提示，并记录每天的完成情况。

## 功能

- 自定义每日打卡任务。
- 为每项任务设置每日打卡次数和对应提醒时间。
- 查看任务的每日完成进度，并手动完成打卡。
- 到达提醒时间时发送通知，并尝试显示全屏提醒界面、播放铃声和震动。
- 添加提醒时间后，可选择将每日闹钟同步到手机时钟应用；闹钟备注包含任务名称和次数序号。
- 设备重启或系统时间、时区变化后，重新安排应用内提醒。
- 在提醒界面完成打卡。

## 兼容性

- 最低版本：Android 8.0（API 26）。
- 编译 SDK：36；目标 SDK：35。
- 使用 Kotlin、Jetpack Compose 和 Gradle Kotlin DSL。

应用提醒依赖 Android 的通知与精确闹钟能力。首次使用时，请按系统提示授予通知权限，并在系统设置中允许应用安排精确闹钟。全屏提醒是否显示、锁屏时是否点亮屏幕，可能受 Android 版本、厂商系统及用户权限设置影响；应用无法保证在所有设备上绕过系统限制。同步到系统时钟的功能也需要设备上存在能够处理系统闹钟请求的时钟应用。

## 安装 APK

在仓库的 `app/build/outputs/apk/debug/app-debug.apk` 下载 Debug APK，传到 Android 手机上安装。安装时如果系统询问是否允许安装未知来源应用，请确认 APK 来源可信后再按系统提示操作。

此 Debug APK 主要用于测试。面向正式分发时，建议使用自己的签名密钥构建 Release APK，并妥善保管签名密钥。

## 从源码构建

需要安装 JDK 17 和 Android SDK，并配置好 Android SDK 环境。项目使用 Gradle Wrapper，可在项目根目录执行：

```bash
./gradlew assembleDebug
```

Windows 命令提示符或 PowerShell：

```powershell
.\gradlew.bat assembleDebug
```

构建产物位于：

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 使用说明

1. 安装并打开应用。
2. 创建打卡任务，填写任务名称、每天需要完成的次数和各次提醒时间。
3. 按需选择是否同步相同时间的每日闹钟到系统时钟。
4. 在系统设置中为应用启用通知和精确闹钟权限，以获得更完整的提醒体验。
5. 到达提醒时间后，可通过提醒界面或应用任务列表完成打卡。

## 项目结构

```text
app/src/main/java/cn/cloudlane/checkin/
├── MainActivity.kt                 # 主界面与任务操作
├── alarm/AlarmScheduler.kt         # 安排与取消每日提醒
├── alarm/AlarmReceiver.kt          # 接收提醒及系统重启、时间变化事件
├── data/CheckinStore.kt            # 本地任务和打卡记录存储
└── ui/ReminderActivity.kt          # 锁屏提醒界面
```

## 权限说明

应用声明了通知、精确闹钟、全屏通知、震动及开机完成接收等权限，用于提供定时提醒、铃声震动和重启后恢复提醒等功能。Android 系统可能要求用户在设置中单独授权精确闹钟或全屏通知；权限名称及设置入口会因系统版本和设备厂商而异。
